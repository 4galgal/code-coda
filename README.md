# The Good Place

A 2D game created in Processing as part of the Code:Coda programme. The
game features a moving train, a falling character, lives, scoring,
increasing difficulty, and a game-over/restart flow.

Gameplay:

The player interacts with the game using the keyboard while trying to
catch the falling character. The game tracks the player's lives and
score, and difficulty increases as the game progresses.

> This repository contains several `.pde` files from different stages of
> development. `TheGoodPlace8.pde` appears to be the most developed game
> version, while `nitz1D.pde` contains supporting code used by the
> project.

Controls:

-   **Arrow keys:Mov** /control the player during gameplay.
-   **Enter:** Restart after game over.

Check the controls in the source code and update this section if the
in-game instructions differ.

How to Run:

1.  Install [Processing](https://processing.org/download).
2.  Clone or download this repository.
3.  Open the project in Processing.
4.  Open the main sketch, `TheGoodPlace8.pde`.
5.  Make sure the supporting `nitz1D.pde` code and any image/audio
    assets referenced by the sketch are available in the project.
6.  Click **Run** in Processing.

If Processing reports missing images, audio, or other resources, check
that the required files are placed in the sketch's `data` folder and
that their filenames match the paths used in the code.


Development Notes:

This repository preserves multiple versions from the project's
development. The latest-looking version may not necessarily be fully
finished, so test the game in Processing before treating it as a final
release.
